# iris-data-cleaning-project
Python project for cleaning and analyzing the Iris dataset.

## 📌 Project Overview
- Loaded the Iris dataset using `pandas`
- Inspected data types and structure
- Removed 3 duplicate rows
- Performed statistical summary
- Created visualizations:
  - Count plot of species
  - Pair plot to explore feature relationships
  - Heatmap showing feature correlations

## 🛠️ Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn

## 📁 Files Included

- `iris_cleaning.py`: Python script with all data cleaning and EDA steps
- `iris_cleaned.xlsx`: Final cleaned dataset
